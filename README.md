# Overview

I created a Java program called "Witch's Potion Shop." This program is a console-based application that lets users run a small magical shop. Users can view the shop's inventory, sell potions and ingredients, add new products, and check shop statistics. The program keeps track of the shop's gold, sales, and remaining inventory. It saves and loads inventory and shop statistics using CSV files, so the information is available when the program is reopened.


I created this program to improve my Java skills and build a functional application. As a beginner, I wanted a project that would help me practice the basics and understand how different parts of a program work together.
